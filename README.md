# 競馬予想AI（前日情報ベース・2モデル構成）

前日までに確定している情報だけを使って予想し、性格の異なる2つのモデルの結果と、
レース単位の自信度を出力します。

## 構成

| モデル | 目的変数 | オッズ | 狙い | 向く券種 |
|---|---|---|---|---|
| **A: 的中率重視** | 3着以内 | **使わない** | 市場と独立した純粋な能力評価 | 複勝・ワイド |
| **B: 期待値重視** | 1着 | **前日オッズを使用** | 市場情報を取り込んだ高精度な勝率推定 → 期待値計算 | 単勝・馬連 |

Aはオッズを見ないので「人気だから上位」という循環が起きず、市場との乖離＝妙味の発見にも使えます。
Bは市場情報を取り込むぶん勝率推定は正確になりますが、そのままだと人気馬をなぞるだけなので、
**推定勝率 × オッズ = 期待値** が1.0を超える馬だけを買う、という使い方をします。

### データ取得についての制約

**前日オッズは過去に遡って取得できません。** netkeiba の過去レースページに残っているのは
確定オッズ（発走時点）だけです。検証では確定オッズを前日オッズの代わりに使っています。
確定オッズの方が直前情報を含むぶん情報量が多いので、検証結果は実運用よりやや良く出ます。
馬場状態も同様で、検証では実際の馬場を、運用では前日の予報を使うことになります。
この差は結果を見るときに割り引いてください。

**血統（種牡馬）は取得していません。** 馬ごとに別ページへのアクセスが必要で、
リクエスト数が数倍になるためです。`sire_id` 列があれば自動で血統特徴量が有効になります。

アクセス間隔は1秒に設定しています。netkeiba の利用規約を確認のうえ、個人利用の範囲で使ってください。
公式かつ確実な手段が必要なら JRA-VAN Data Lab（有料）を検討してください。

## 必要なデータ

1行 = 1レース1頭。過去3〜5年分（3万行以上）が最低ライン、10年分あると安定します。

**必須列**

```
race_id, date, horse_id, venue, surface(芝/ダ), distance, turn(右/左),
class_level(1〜6の数値), horse_no, frame_no, age, sex, weight_carried,
jockey_id, trainer_id, sire_id, going_forecast, odds_prev_win, finish_pos
```

スクレイパーはこれに加えて `corner_pos`（通過順）、`prize`（賞金）、`last3f`（上がり3F）、
全券種の払戻を取得します。通過順からは脚質、賞金からは実績が特徴量として作られます。

**あると精度が上がる列**

```
odds_prev_place_low   前日複勝オッズ下限
training_time_last    最終追い切りタイム
last3f                上がり3F（過去走の特徴量として自動利用）
payout_win/payout_place  バックテストの回収率計算に必要
```

データ取得は JRA-VAN Data Lab（有料・公式）か netkeiba のスクレイピングが一般的です。
スクレイピングする場合は各サイトの利用規約とアクセス間隔に注意してください。

## 使い方

```python
import pandas as pd
from src.predict import KeibaPredictor, format_report

history = pd.read_csv("history.csv")   # 過去の全レース結果
entries = pd.read_csv("tomorrow.csv")  # 明日の出走表（finish_pos なし、前日オッズあり）

p = KeibaPredictor().train(history)
pred = p.predict_day(history, entries)          # ← history と結合して特徴量を作るので両方渡す
reports = p.build_report(pred, min_grade="A", top_n=5)
print(format_report(reports))
```

`min_grade="A"` で自信度A級以上のレースだけに絞り込みます。`top_n` で点数を制限。

## 自信度の仕組み

レースごとに次の4つを合成してスコア化します。

1. **突出度** — 本命馬の確率そのもの
2. **差** — 1位と2位の確率差（2強なら低い）
3. **混戦度** — 正規化エントロピー（横並びなら読めない）
4. **一致度** — AとBの本命が一致するか（市場と独自評価の合致）

スコアはそのままでは意味がないので、バックテストの実測的中率でキャリブレートして
S/A/B/C に落とします。合成データでの検証例：

```
grade  レース数  A複勝的中率  B単勝的中率
S        153     77.8%      49.7%
A        229     67.7%      45.4%
B        381     62.2%      39.4%
C        763     49.0%      26.7%
```

C級を捨ててS/A級だけ買う、という運用が想定用途です。

## データリーク対策

競馬予想モデルで最も多い失敗が、当日情報の混入です。`src/schema.py` の `LEAK_COLS` に
**馬体重・確定オッズ・確定人気・上がり3F・通過順・実馬場状態**を列挙し、
特徴量選択時に機械的に排除しています。列を追加するときは必ずこのリストを更新してください。

集計特徴量（馬の勝率、騎手の成績など）も `cumsum - 自分自身` 方式で
「そのレースより前のデータのみ」から計算しています。ランダム交差検証は使わず、
ウォークフォワード（過去で学習→未来で検証→窓をずらす）のみで評価します。

## 連勝式の確率計算

単勝の勝率から2着・3着の確率を出すのに、Lo & Bacon-Shone の指数割引モデルを使っています。

```
P(1着a)     = s_a / Σs
P(2着b|a)   = s_b^λ2 / Σ_{j≠a} s_j^λ2      λ2 ≈ 0.81
P(3着c|a,b) = s_c^λ3 / Σ_{j≠a,b} s_j^λ3    λ3 ≈ 0.65
```

素朴な Harville モデル（λ=1、2着以降も同じ強さ比で配分）は人気馬の連対率を
過大評価することが知られています。λ<1 は「2着・3着争いは1着争いより混戦になる」
という実際の傾向を表します。λ は `fit_lambdas()` で自分のデータから推定し直せます。

連勝式のオッズが手元にない場合は、前日単勝オッズから市場の勝率を復元し、
同じモデルで推定配当を計算しています。実オッズがあれば `build_bets(actual_odds=...)`
に渡してください。そちらの方が当然正確です。

## 精度を上げるための次の一手

- **ペース・脚質**：過去走の通過順から逃げ/先行/差し/追込を分類し、レースの想定ペースと組み合わせる
- **タイム指数**：走破タイムを馬場差・距離・クラスで補正した独自指数（スピード指数系）
- **枠順×コース**：コース別の枠順有利不利は距離ごとに大きく異なるので交互作用を明示的に入れる
- **ラベルの工夫**：着順そのものより着差ベースの連続値で学習した方が情報量が多い
- **LambdaRank**：レース内の順位付けに特化した学習目的に切り替える
- **連勝式オッズの取り込み**：馬連・3連複の実オッズを前日に取得できれば、推定配当ではなく実配当で期待値を計算できる。妙味の判定精度が大きく変わる

## 現実的な注意

- JRAの控除率は単勝約20%、馬連約22.5%、3連単約27.5%です。何もしなければ回収率は
  その分だけマイナスから始まります。合成データでも期待値フィルタ後の単勝回収率は
  90%前後にとどまり、控除率の壁を越えるのは容易ではないことが確認できます。
- 「的中率が高い」ことと「儲かる」ことは別です。本命を買えば的中率は上がりますが
  回収率は上がりません。モデルAは的中率、モデルBは回収率、と役割を分けているのはそのためです。
- バックテストの成績は、パラメータをいじるほど楽観的になります（過学習）。
  検証期間の最後の1年は一度も触らずに取っておき、最終確認だけに使ってください。
- 3連単は控除率27.5%と最も不利な券種です。当たれば大きいぶん、長期的な期待値は最も削られます。回収率を重視するなら馬連・ワイドの方が土俵として有利です。
- 合成データのデモで一部の回収率が100%を超えていますが、これはダミーの市場オッズが甘いだけで、実データでこの数字は出ません。必ず自分のデータでバックテストしてください。
- これは分析ツールであり、投資助言ではありません。馬券は余剰資金の範囲で。
